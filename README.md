# 🏏 IPL Win Predictor

Predict the possible winner of an IPL match using a Machine Learning model.

## 🚀 Live Demo

🔗 https://ipl-win-predictor-sriharshavemula.streamlit.app/

## ✨ Features

- Select two IPL teams.
- Choose the match venue.
- Predict the possible match winner.
- View prediction probabilities.
- Interactive web interface with a cricket stadium background.

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Machine Learning
- Git and GitHub

## ⚙️ Run Locally

1. Clone this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Start the application:

   `streamlit run app.py`

## 🎯 Project Goal

This project demonstrates how a trained Machine Learning model can be integrated into a web application to predict possible IPL match outcomes.
